# Archive

These are kept for context (useful if you're wondering why something was built a certain way) but are **not maintained** and may describe behavior, versions, or architecture that no longer matches the current codebase. For current information, see the root `README.md`, `CHANGELOG.md`, and `CLAUDE.md`.
